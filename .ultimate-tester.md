# Ultimate Tester profile

## Start
- Command: ULTIMATE_TESTER_HOME=/tmp/ut-profile-test npm run dev
- Ready when: http://localhost:4601 returns 200
- Seed: rm -rf /tmp/ut-profile-test

## Allowed URLs
- http://localhost:4601
- Never touch: http://localhost:4600 (the developer's real Ultimate Tester engine), https://ultimate-tester.kreativekorna.com, https://github.com/codellyson/ultimate-tester/releases

## Test accounts
- One saved sign-in per persona, made in Ultimate Tester setup. Never a password here.

## Personas
- new-user: First launch with no apps added yet, so the onboarding shows. No sign-in.
- developer: Has apps added, with profiles, personas and past runs. No sign-in.

## Must never break
- First launch shows Getting started; Try it on a sample app adds the sample app and Tess drafts its plan
- The plan card reads in plain words ("I start it with ...", "Pages I may open") and each row can be edited and saved
- Home lists the sample app, and its remove button asks first; Cancel keeps it
- The New test menu lists My changes, Last commit and Something else (open it, never start a test)
- ⌘K opens the command list with Getting started and Remove entries

## Existing checks
- node --test test/lib.test.js

## Notes for Tess
- Never start a test (Test, Test again, Start my first test, Read my repo on a real folder): each one runs another Claude session.
- Never click Choose your app's folder: it opens a folder picker on the developer's screen. Use Try it on a sample app.
- Never confirm a Remove or Delete except on the sample app inside this run's own data folder.
